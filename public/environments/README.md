# HDR Environment Maps

Эта папка содержит HDR файлы для освещения 3D сцен.

## Где скачать HDR файлы

### Рекомендуемые источники:

1. **Poly Haven** (https://polyhaven.com/hdris)
   - Бесплатные HDR карты высокого качества
   - Разные разрешения (1k, 2k, 4k, 8k)
   - Форматы: HDR и EXR

2. **HDRI Haven** (https://hdrihaven.com)
   - Большая коллекция бесплатных HDR карт
   - Категории: outdoor, indoor, studio, nature

3. **ambientCG** (https://ambientcg.com)
   - Бесплатные текстуры и HDR карты

## Рекомендуемые HDR файлы для продуктовой съёмки:

- `studio_small_03_2k.hdr` - студийное освещение (нейтральное) - **текущий выбор**
- `lebombo_2k.hdr` - интерьерное освещение (apartment preset)
- `empty_warehouse_01_2k.hdr` - нейтральное окружение (warehouse preset)

## Как использовать

1. Скачайте HDR файл (рекомендуется разрешение 2k для лучшего качества)
2. Поместите файл в эту папку (`public/environments/`)
3. Обновите путь в `ModelViewer.jsx`:
   ```jsx
   <Environment
     files="/environments/your-file.hdr"
     environmentIntensity={1.1}
     background={null}
   />
   ```

## Разрешения HDR файлов

### 1k (1024x512)
- **Размер файла:** ~1-2 MB
- **Плюсы:** Быстрая загрузка, меньше трафика
- **Минусы:** Меньше деталей в отражениях
- **Использование:** Для мобильных устройств или медленного интернета

### 2k (2048x1024) ⭐ **Рекомендуется**
- **Размер файла:** ~3-5 MB
- **Плюсы:** Хороший баланс качества и размера
- **Минусы:** Немного больше размер файла
- **Использование:** Для desktop и хорошего интернета

### 4k (4096x2048)
- **Размер файла:** ~10-15 MB
- **Плюсы:** Отличное качество отражений
- **Минусы:** Большой размер файла, медленная загрузка
- **Использование:** Для высококачественных презентаций

## Примечание

- Текущая настройка использует **2k разрешение** для оптимального баланса
- Файлы HDR обычно весят 1-15 MB в зависимости от разрешения
- Убедитесь, что файл имеет расширение `.hdr` или `.exr`
