# План разработки сайта-каталога производства кресел ROBUSTINO

## 📋 Общая информация о проекте

### Технологический стек
- **Frontend Framework**: Vite + React
- **Анимации**: GSAP (GreenSock Animation Platform)
- **3D модели**: Three.js / React Three Fiber для работы с GLB моделями
- **Стилизация**: Tailwind CSS / CSS Modules
- **Роутинг**: React Router
- **Управление состоянием**: Zustand / Redux Toolkit
- **Backend**: Node.js + Express / Supabase / Firebase
- **База данных**: PostgreSQL / MongoDB / Firebase Firestore
- **Хранилище файлов**: AWS S3 / Firebase Storage / Cloudinary

### Библиотеки для работы с 3D моделями

**Да, библиотеки НЕОБХОДИМЫ!** Для отображения GLB моделей в браузере рекомендуется:

1. **Three.js** - базовая библиотека для работы с 3D в браузере
2. **React Three Fiber** - React-обертка над Three.js (рекомендуется для React проектов)
3. **@react-three/drei** - коллекция полезных хелперов для React Three Fiber
4. **@react-three/postprocessing** - эффекты постобработки для улучшения визуала

**Преимущества использования React Three Fiber:**
- Декларативный подход (как в React)
- Автоматическая оптимизация производительности
- Легкая интеграция с React компонентами
- Встроенная поддержка GLB/GLTF моделей

## 📄 Детальное описание страниц

### 1. Главная страница (Home)

#### 1.1 Hero блок
- **Элементы:**
  - Крупный заголовок с призывом к действию
  - Подзаголовок с описанием компании
  - CTA кнопки ("Каталог", "Связаться")
  - 3D модель кресла в качестве фона (интерактивная, с автовращением)
- **Анимации GSAP:**
  - Плавное появление текста при загрузке
  - Параллакс эффект при скролле
  - Анимация кнопок при наведении

#### 1.2 О компании
- **Элементы:**
  - Краткое описание компании
  - Ключевые преимущества (иконки + текст)
  - Статистика (годы на рынке, проектов, клиентов)
- **Анимации:**
  - Появление блоков при скролле
  - Анимация счетчиков статистики

#### 1.3 Продукция (Каталог)
- **Элементы:**
  - Фильтры по категориям кресел
  - Сетка карточек продуктов (4-6 товаров на главной)
  - Каждая карточка: миниатюра 3D модели, название, краткое описание, цена
  - Кнопка "Смотреть весь каталог"
- **Анимации:**
  - Stagger эффект появления карточек
  - 3D модель вращается при наведении
  - Smooth transition при клике

#### 1.4 Реализованные объекты
- **Элементы:**
  - Галерея проектов (слайдер/карусель)
  - Фото объекта, название, описание
  - Логотипы клиентов
- **Анимации:**
  - Плавная смена слайдов
  - Zoom эффект при наведении на фото

#### 1.5 Блог
- **Элементы:**
  - 3-4 последние статьи
  - Превью статьи: изображение, заголовок, дата, краткое описание
  - Кнопка "Все статьи"
- **Анимации:**
  - Появление карточек при скролле
  - Hover эффекты

#### 1.6 FAQ
- **Элементы:**
  - Аккордеон с вопросами и ответами (5-7 вопросов)
  - Иконки + / -
- **Анимации:**
  - Плавное раскрытие/сворачивание ответов
  - Анимация иконок

## 🎨 UI/UX рекомендации

### Дизайн система
- **Цветовая палитра:**
  - Основной цвет (primary) - связанный с брендом
  - Вторичный цвет (secondary)
  - Акцентные цвета
  - Нейтральные (серые оттенки)
- **Типографика:**
  - Шрифт заголовков (например, Montserrat, Roboto)
  - Шрифт текста (например, Open Sans, Inter)
- **Отступы и сетка:**
  - 8px grid system
  - Консистентные отступы

### Адаптивность
- Mobile First подход
- Breakpoints:
  - Mobile: < 768px
  - Tablet: 768px - 1024px
  - Desktop: > 1024px
- Адаптивная 3D модель (упрощенная на мобильных для производительности)

### Производительность 3D
- Lazy loading 3D моделей
- Level of Detail (LOD) для моделей
- Оптимизация текстур
- Ограничение полигонов в моделях

## 🎯 Backend варианты

### Вариант 1: Supabase (Рекомендуется для быстрого старта)
**Плюсы:**
- Готовая аутентификация
- PostgreSQL база данных
- Хранилище файлов
- Real-time возможности
- Бесплатный tier

**Минусы:**
- Зависимость от сервиса
- Ограничения бесплатного плана

### Вариант 2: Firebase
**Плюсы:**
- Простая настройка
- Firestore NoSQL
- Firebase Storage
- Хорошая документация

**Минусы:**
- Стоимость при росте проекта
- NoSQL может быть избыточным

### Вариант 3: Custom Backend (Node.js + Express)
**Плюсы:**
- Полный контроль
- Гибкость
- Любая БД на выбор

**Минусы:**
- Больше времени на разработку
- Нужно настраивать инфраструктуру

## 💡 Дополнительные рекомендации

### Оптимизация 3D моделей
- Используйте Blender или другие 3D редакторы для оптимизации GLB файлов
- Рекомендуемый размер модели: до 5MB
- Рекомендуемое количество полигонов: 10k-50k для desktop, < 10k для mobile
- Используйте сжатие текстур (Draco compression)

### Анимации GSAP
- Используйте ScrollTrigger для scroll-based анимаций
- Создайте переиспользуемые анимации в utils/animations.js
- Оптимизируйте анимации для мобильных устройств

### SEO
- Используйте React Helmet для управления meta тегами
- Создайте уникальные meta описания для каждой страницы
- Используйте семантические HTML теги
- Оптимизируйте изображения (WebP формат)
- Добавьте структурированные данные (Schema.org)

### Безопасность
- Валидация всех форм на frontend и backend
- Защита от XSS атак
- Rate limiting для API
- Безопасное хранение токенов
- HTTPS обязательно

### Аналитика
- Google Analytics / Yandex Metrika
- Отслеживание взаимодействий с 3D моделями
- Отслеживание конверсий (отправка форм)
